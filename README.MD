# Проект PyBD

## Описание
Проект, который будет получать информацию о работодателях и вакансиях с платформы hh.ru в России,
создавать базу данных и сохранять в неё данные на основе psycopg2, а так же предложит
некоторые варианты взаимодействия с данными из таблицы\
**В данный момент находится в разработке, просим проявить терпение.**

## Установка:
1. Клонируйте репозиторий:
```
https://github.com/AndTiho/PyBD.git
```
2. Установите зависимости:
```
poetry install
```
## Использование
**Здесь будет информация чуть позже**

## Запуск и ожидаемое поведение программы
Для запуска программы воспользуйтесь:
